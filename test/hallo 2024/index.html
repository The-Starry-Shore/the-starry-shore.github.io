    🎃 The Halloween Event Shop!! 🎃¶

    How to get Halloween Tokens?¶

    • As a Player: You get 1 token for each session you play
    • As a DM: You get 3 token for each session you host

    Rules:¶

    • Minimum time for the session to count is 3 hours.
    • Tokens collected are player-based, not character-based.
    • Playing/Hosting 6 hours or more counts as 2 sessions.
    • The Cosmic Calendar's double rewards doesn't count as double for event progression.
    • To buy a certain reward, it needs to be logged in the event channel using the following template below.
